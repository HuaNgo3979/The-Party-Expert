## ⚠️ Before you commit this publicly
This dataset was **provided by RMIT** for the assignment, so it may be course material
rather than yours to redistribute. Safer options:
- Keep the repository **private**, or
- Commit only a small **sample** (e.g. 20 rows) plus the header description, or
- Exclude the raw file and rely on the screenshots in `assets/screenshots/`.

By default `.gitignore` **ignores `*.xlsx` in this folder** so you don't publish it by
accident. If you're sure it's fine to share, remove that line from `.gitignore` (or run
`git add -f orange/data/TPE-SalesDataset.xlsx`).
